# Portfólio — Gabriel

Site pessoal em React + Vite. Visual editorial, seções de projetos, sobre, trajetória e contato.

## Rodar localmente

```bash
npm install
npm run dev
```

## Personalizar

Edite `src/data.ts`: nome, e-mail, links, projetos, skills e linha do tempo.

Estilos com Tailwind CSS v4 (`@tailwindcss/vite`). Tokens de cor e fonte estão em `src/index.css` (`@theme`).

Títulos usam **Fraunces** (SIL Open Font License, Google Fonts). Interface em **Syne**, também gratuita.
